Phoenix Canal-Adjacent Transit Ridership Analysis

Project Overview
This project evaluates whether Valley Metro stop-level bus ridership data can support a before-and-after analysis of transit activity near Grand Canalscape Phase 3 access points. Grand Canalscape Phase 3 is a dedicated off-street multi-use trail upgrade in west Phoenix that improved pedestrian and bicycle access along the Grand Canal corridor.
During analysis, I found that the available dataset was last updated shortly after the project opened, which limits the ability to complete a reliable post-opening evaluation at this time. As a result, this version focuses on pre-opening ridership patterns, stop selection, methodology development, and data-readiness assessment.

Research Question
Can Valley Metro stop-level ridership data be used to evaluate transit ridership trends near the Grand Canalscape Phase 3 upgrades?

Project Goals
- Identify bus stops that provide access to Grand Canalscape Phase 3.
- Select comparison stops near the Highline Lateral corridor.
- Compare pre-opening ridership patterns between the two corridors.
- Build an Excel-based structure for future before-and-after analysis.
- Document data limitations and next steps.

Data Source
The analysis uses Valley Metro stop-level ridership data from 2022 through 2025.
The dataset includes quarterly average ridership by stop.
Important limitation: the dataset used in this project was last updated on April 28, 2025. Because Grand Canalscape Phase 3 opened on March 29, 2025, the dataset does not contain enough complete post-opening ridership data to evaluate the project’s full impact.

Methodology

Treatment Corridor
The treatment group includes selected bus stops near Grand Canalscape Phase 3 access points. These stops were selected because they are located near canal entrances, crossings, or trail access areas that could plausibly be affected by improved pedestrian and bicycle connectivity.

Comparison Corridor
The comparison group includes selected bus stops near the Highline Lateral corridor. These stops were selected because they are also canal-adjacent, but did not receive the same type of recent infrastructure investment during the study period.
This comparison allows the project to examine pre-opening ridership patterns between an improved canal corridor and another canal-adjacent corridor.

Current Analysis
The workbook currently includes:
- Raw Valley Metro stop-level ridership data
- Selected Grand Canalscape Phase 3 stops
- Selected Highline Lateral comparison stops
- Quarterly average ridership calculations
- Summary tables comparing the selected corridors
- Charts showing available pre-opening ridership patterns

Note: 2025 Q2 and Q3 values were excluded from the main analysis because the dataset was last updated in April 2025. Those quarters appear incomplete and are not reliable for evaluating ridership trends.

Key Finding
The current dataset is useful for building the analysis structure and understanding pre-opening ridership patterns, but it is not sufficient to evaluate post-opening ridership changes following Grand Canalscape Phase 3.
A complete impact analysis would require updated stop-level ridership data covering several quarters after March 2025.

Limitations
- The dataset does not include enough complete post-opening observations.
- 2025 Q2 and Q3 appear incomplete due to the dataset update date.
- This project does not establish causation.
- Service frequency changes were not incorporated.
- Pedestrian and bicycle usage data were not available.

Next Steps
This project is structured so it can be updated once more complete post-opening data becomes available. 

Future improvements could include:
- Updated Valley Metro stop-level ridership data for complete post-opening quarters
- Pedestrian and bicycle count data
- Service frequency adjustments
- Expanded comparison corridors
- A Tableau dashboard or interactive map
